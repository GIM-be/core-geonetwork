xx/01/2021

  1. Fixed advanced view in editor for services metadata
  2. "Vlaamse Open data" keyword is no longer automatically added for services metadata
  3. Fixed cardinality for fields dct:title, dct:description, dcat:endpointUrl and dcat:endpointDescription
  4. Added dcat-ap 2.0 dct:accessRight and dct:license elements to the XSD schema

21/01/2021

  1. Renamed plugin from "dcat-ap-for-servives" to "metadata-dcat"
  2. Updated with latest changes done on dcat-ap v1.2 plugin
  3. Changed XML namespace from http://data.vlaanderen.be/ns/metadata-dcat# to http://data.vlaanderen.be/ns/metadata-dcat#
  4. Added two new thesauri for mvs:statusVanGebruik and mvs:statusVanOntwikkeling and update editor to use them
  5. Added dct:publisher in services metadata schema and make it editable and viewable
  6. Updated service's fields with latest cardinalities

13/01/2021

  1. Slightly improved changelog's readability
  2. Added the field dcat:accessService to dataset distribution
  3. Modified view to display the content of dcat:accessService as a clickable link and added translations
  4. Updated the dcat-ap plugin and the core with the latest changes of the dcat-ap 1.2 branch
  5. When linking a dataset to a service, we now can also modify the linked dataset with the URL of the service in the mean time:
  6. Fixed a file encoding issue

07/12/2020

  1. Added changelog page
  2. Added link to the changelog page in the top toolbar
  3. Added the namespace <http://data.vlaanderen.be/ns/metadata-dcat#> to the dcat-ap plugin
  4. Added the new elements to the schema and makes them viewable and editable in the new section "Service informatie"
    • mvs:authenticatie
    • mvs:dienstverleningsKwaliteit
    • mvs:doelpopulatie
    • mvs:gebruiksbepaling
    • mvs:statusVanGebruik
    • mvs:statusVanOntwikkeling
    • mvs:wettelijkeBeperkingen
  5. Added translations and tooltips for these new fields

20/10/2020

  1. Fixed a bug where a dct:identifier was added when clicking on the + button to add a keyword
  2. Fixing few translations: labels sometimes starting with lower case, sometime with upper-case => All changed to upper-case
  3. Fixed a bug where the content of vcard:hasUrl was edited instead of the vcard:hasUrl/@rdf:resource attribute
  4. Better indexing for the services metadata for fields
    • dcat:servesDataset
    • dcat:endpointUrl
    • dcat:endpointDescription
    • dcat:landingPage
  5. Improve view:
    • dcat:endpointDescription is now displayed. If it contains links, they will be clickable
    • Added missing translations for the side bar
    • Fixed styles for nested tables
  6. Update schematron rules to prevent error when editing a services (error of type "dcat:dataset is a required property…") allowing to have valid service records
  7. Added schematron validation rules for
    • dcat:endpointUrl
    • dcat:DataService/dcat:contactPoint
    • dcat:servesDataset
    • dcat:landingPage
  8. Added the @rdf:about attributes on dcat:DataService schema and handle it when creating a new service record

14/10/2020

  1. New elements have been added to the XSD and the editor. Here is the list of all the editable fields for dcat-ap services metadata:
    • dct:identifier
    • dct:title
    • dct:description
    • dcat:endpointUrl
    • dcat:endpointDescription
    • dcat:servesDataset
    • dcat:landingPage
    • dcat:contactPoint
    • dcat:keyword
    • dct:language
    • owl:versionInfo
  2. Translations have been fixed for existing fields and added for the new ones
  3. We can now couple a dataset to a service via the search box. Doing so will add a new dcat:servesDataset element pointing at the dataset. (Please notice that this must be done by clicking the first "Link naar een dataset" button in the dropdown of the "Toevoegen" button. The two others button in this dropdown must be evaluated and maybe removed).
  4. The coupled dataset will be displayed in the editor and in the view as a related dataset (on the right side bar)
  5. The title and the description of services are now displayed in the search and view pages (instead of a blank lines). The rest of the view was not changed yet; which mean that some field might be missing from the view.
  6. Modified the template for services to add the new elements. However, this is not necessary to recreate existing metadata from this template. The new elements can be added via the + button in the editor.
